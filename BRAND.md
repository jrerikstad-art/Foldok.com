# Foldok brand mark — `[…]`

**Wordmark:** FOLDOK  
**Mark:** `[…]` (ellipsis inside square brackets)

## Why this mark

1. **Code & syntax** — Brackets are the universal symbol for arrays, data
   blocks, and structured code. Foldok is an AI compiler: raw folder data →
   structured documents.

2. **The data gap** — In docs and editors, `[…]` means truncated or missing
   text. Foldok’s job is reading unstructured folders and filling those gaps
   (the `[MANGLER]` / resolve-gaps loop).

3. **Folder / document geometry** — The hard 90° corners of `[` `]` echo
   paper edges and file tabs. The mark uses `border-radius: 0` for the same
   reason.

## Usage

- Header / hub: monospace **`[…]`** in signal yellow (bold, large, no tile), then **FOLDOK**.
- Prefer the Unicode ellipsis `…` inside brackets (not three ASCII dots).
- No rounded tile behind the mark — the brackets carry the geometry.
